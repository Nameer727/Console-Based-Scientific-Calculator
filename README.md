# Scientific Calculator & Unit Converter (C++)

A console-based Scientific Calculator and Unit Converter built using C++. This project can perform arithmetic operations, roots and powers, logarithmic calculations, trigonometric functions, factorial calculations, and various unit conversions.

## Features

### Arithmetic Operations
- Addition (2, 3, and 4 numbers)
- Subtraction
- Multiplication (2, 3, and 4 numbers)
- Division

### Root & Power
- Power Calculation
- Square Root
- Cube Root
- Nth Root

### Logarithm
- Natural Logarithm (ln)
- Base-10 Logarithm (log)
- Custom Base Logarithm

### Trigonometry
- sin, cos, tan
- cosec, sec, cot
- Inverse Trigonometric Functions
- Degree to Radian Conversion

### Unit Conversion

#### Length
- Inch ↔ Centimeter
- Foot ↔ Meter
- Yard ↔ Meter
- Mile ↔ Kilometer
- Nautical Mile ↔ Meter
- Parsec ↔ Kilometer

#### Area
- Acre ↔ Square Meter

#### Volume
- Liter ↔ US Gallon
- Liter ↔ UK Gallon

#### Speed
- Kilometer/Hour ↔ Meter/Second

#### Mass
- Ounce ↔ Gram
- Pound ↔ Kilogram

#### Pressure
- Atmosphere ↔ Pascal
- mmHg ↔ Pascal
- kgf/cm² ↔ Pascal
- lbf/in² ↔ kPa

#### Energy
- Joule ↔ Calorie
- Joule ↔ kgf·m

#### Power
- Horsepower ↔ Kilowatt

#### Temperature
- Celsius ↔ Fahrenheit

### Factorial
- Factorial Calculation using Iteration
